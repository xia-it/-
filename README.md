MusicFree 壁纸脚本 · 使用说明
================================

一、这个包是什么
    一个 MusicFree 壁纸脚本。脚本会读取包内固定的那张图片作为壁纸/背景，
    所以想换成自己的图，不需要改代码，只要把图片换掉、名字对上就行。

二、换图三步
    1. 解压这个压缩包；
    2. 把你的图片放进去，覆盖原来那张，并把文件名改成和原图【完全一样】
       （文件名、后缀名、大小写都要一致；原图是 png，你的图也要是 png）；
    3. 把文件夹【里的内容】重新压缩成 zip（不要多套一层文件夹，不要用 rar/7z）。

    提示：手机上用 MT 管理器 / ZArchiver 打开 zip 直接替换文件最快，
          不用解压再压缩。

三、安装
    MusicFree → 设置 → 插件管理 → 安装本地插件 → 选中重新压好的 zip。
    如果提示已存在或安装失败，先卸载旧插件再装。

四、图片建议
    格式：和原图一致（png 或 jpg）
    比例：跟手机屏幕一致（竖屏 9:19.5 左右），桌面端用横屏
    分辨率：1080×2400 起步即可
    体积：2MB 以内
    内容：主体放中间，边缘容易被裁；整体偏暗一点，界面文字更清楚

五、常见问题
    Q：换了图还是原图？
    A：检查文件名（含后缀、大小写）、是不是 zip、有没有多套一层文件夹；
       都没问题就卸载插件重装，再重启 App。

    Q：能放动图吗？
    A：包内只读一张静态图，gif 也只当一张图。

    Q：会上传我的图片吗？
    A：不会。脚本只读取包内图片并显示，不联网。
